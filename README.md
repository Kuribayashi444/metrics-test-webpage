# metrics-test-webpage

Тестовая статическая страница для проверки self-hosted систем веб-аналитики
[Rybbit](https://github.com/rybbit-io/rybbit) и
[Openpanel](https://github.com/Openpanel-dev/openpanel).

Публикуется через GitHub Pages и открывается по публичному URL
(`https://<аккаунт>.github.io/metrics-test-webpage/`), чтобы трекеры
корректно фиксировали адреса страниц на реальном домене.

## Секции страницы

- **Главная** (`#home`) — заголовок и CTA-кнопки («Начать», «Узнать больше»).
- **Форма** (`#form`) — демо-форма (имя + email) с валидацией и подтверждением отправки.
- **Кнопки** (`#buttons`) — скачивание демо-отчёта, копирование промокода, показ уведомления.

## Аналитика

На страницу подключены оба трекера (самостоятельно развёрнутые инстансы):

- Rybbit — просмотры страниц, autocapture кликов по кнопкам и сабмитов форм,
  кастомные события (`cta_click`, `demo_button_click`, `form_submit`, `promo_copied`).
- Openpanel — просмотры страниц, события через `data-track` и JS API.

В дашбордах обоих инструментов настроена воронка из 3 шагов:
просмотр главной → клик по CTA → отправка формы.
